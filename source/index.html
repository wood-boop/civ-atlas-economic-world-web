本次公开的是已完成的原生经济版本（应用 1.3.0-economy.3，生成器 46）。后续五阶段市场、产权与货币系统仍属于开发规划。

下载本发布版本的对应源码（ZIP） · 版本与 SHA-256 校验信息

源码包含构建脚本、依赖锁文件、程序、运行素材、测试、AGPL-3.0 许可证及第三方素材声明。仅省略 README 展示截图；依赖按锁文件安装。压缩包不含个人存档、凭据、依赖缓存或反编译资料。

  1. 安装 Node.js 22+ 和 pnpm 11.25.0。
  2. 解压后执行 pnpm install --frozen-lockfile。
  3. 执行 pnpm dev 本地运行，或 pnpm build 构建。
