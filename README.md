# Civ Atlas Economic World — public v46

[Play in your browser](https://wood-boop.github.io/civ-atlas-economic-world-web/?seed=7&cells=3000&play=0&gen=46). No ChatGPT or GitHub account is required.

This repository publishes the existing v46 civilization and economy simulation as static files. World simulation and saves run in your browser. It includes no account server, cloud sync, or official AI backend.

[Download the complete corresponding source](https://wood-boop.github.io/civ-atlas-economic-world-web/source/). The archive includes the implemented game and the future autonomous economy architecture and playable update plan. Those future stages are planning documents, not implemented new features. `source/release.json` records the exact commit, tree and SHA-256.
